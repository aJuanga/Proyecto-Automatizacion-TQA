# Proyecto de Automatización – TQA

Repositorio para los scripts, configuraciones y pruebas automatizadas del proyecto de automatización de la materia **TQA** – UNIFRANZ.

Las pruebas automatizadas se aplican sobre el **Sistema HGW** ([aJuanga/sistema_hgw](https://github.com/aJuanga/sistema_hgw)): inicio de sesión por rol, registro de pedidos e inventario.

## Estructura
| Carpeta | Contenido |
|---|---|
| `tests/` | Scripts de pruebas automatizadas |
| `config/` | Configuración de entornos, datos de prueba y drivers |
| `reportes/` | Reportes generados por las ejecuciones |
